# CREATIVION — COMPLETE PROFESSIONAL AGENCY WEBSITE

Build a complete, production-quality, modern full-stack website for a creative digital agency named:

# CREATIVION

Tagline:

**CREATE • INNOVATE • GROW**

Creativion is a modern creative, digital marketing and technology agency that helps businesses build their brand identity, create high-quality content, grow their digital presence, generate leads and build modern digital experiences.

The website must feel like a REAL professional agency website that could be presented to paying clients.

It must NOT look like:
- A generic template
- A SaaS dashboard
- A freelancer portfolio
- A cheap social media agency website
- An over-designed colorful website
- A website full of unnecessary sections
- A website selling subscriptions

The goal is to make visitors immediately understand:

**Who Creativion is → What Creativion does → Why Creativion is different → What work Creativion does → Who Creativion works with → How Creativion works → How to contact Creativion → How to work/join with Creativion.**

# 1. TECHNOLOGY STACK

Use:

## Frontend

- React.js
- Vite
- React Router
- Tailwind CSS
- Framer Motion
- Lucide React or React Icons
- Axios

## Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- REST APIs
- dotenv
- CORS
- Nodemailer or another reliable SMTP/email implementation

## Architecture

Create a clean separation:

frontend/
backend/

Use a professional, scalable folder structure.

Do NOT put the entire application into a few giant files.

Create reusable components and reusable sections.

Use environment variables for all sensitive or configurable information.

Never expose:
- MongoDB URI
- SMTP credentials
- Admin credentials
- API keys
- Private configuration

to the frontend.

# 4. COLOR SYSTEM

Use a very restrained color palette.

Maximum approximately 3-4 primary visual colors.

Primary dark:
Deep near-black / dark navy

Background:
Off-white / very light neutral

Main accent:
Electric blue

Secondary accent:
Subtle orange/coral inspired by the Creativion logo

The website must NOT use:
- 10+ colors
- Rainbow gradients
- Excessive neon
- Random colorful cards
- Every section having a different color

The logo can contain its original colors, but the rest of the website should remain visually controlled.

- Icons
- Important visual details

Maintain professional consistency.

# 27. DIRECT EMAIL FUNCTIONALITY

When the visitor submits the contact form:

Frontend sends request to backend.

Backend validates the form.

Backend stores inquiry in MongoDB.

Backend sends an email notification to the Creativion business email.

Use Nodemailer/SMTP or a reliable transactional email provider.

Use environment variables:

SMTP_HOST
SMTP_PORT
SMTP_USER
SMTP_PASSWORD
CONTACT_EMAIL

Do NOT expose SMTP credentials to frontend.

Email should contain:

New Project Inquiry

Name
Company
Email
Phone
Service
Budget
Project Description
Preferred Contact Method
Submission Time

Also optionally send a professional acknowledgement email to the customer.

Customer acknowledgement:

"Thank you for reaching out to Creativion. We have received your project inquiry and our team will review it shortly."

Do not promise unrealistic response times.
